TEST CASE: LILP-TC-T02-007
TITLE: Consequential object carries relevant temporal context
OBJECTIVE: Establish that an object relied upon for consequential governance identifies the time or temporal state relevant to its creation or applicability.
EXPECTED: The object identifies the material time or temporal state relevant to its creation or applicability before it is relied upon for consequential governance; missing required temporal context remains explicit and is not silently inferred.
FAILURE ORACLE: FAIL if an object is relied upon for consequential governance while a required creation or applicability time or temporal state is absent, ambiguous or silently inferred.

TEST CASE: LILP-TC-T02-008
TITLE: Canonical object identity declares hash algorithm
OBJECTIVE: Establish that the implementation explicitly declares the hash algorithm used to identify an object's canonical byte representation.
EXPECTED: The hash algorithm used for object identity is explicitly declared, is unambiguous for the relevant object identity procedure and can be used with the canonical bytes to reproduce the claimed identifier.
FAILURE ORACLE: FAIL if the object identifier depends on a hash algorithm that is absent, ambiguous, silently substituted or cannot be associated with the canonical byte representation used to produce the identifier.
