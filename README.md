## What this is

LILP is an Elias Systems technical specification and evidence-governance architecture for locking governing state before consequence, logging material state and transitions contemporaneously, and proving bounded claims from preserved evidence.

The architecture separates **capability from authority**.

Technical ability to perform an action does not establish permission to perform that action.

Uncertainty is an admissible state.

Missing evidence or authority is not silently replaced by assumption.

## Operating discipline

### LOCK IT
Freeze the governing state, authority boundary, evidence basis and applicable conditions before consequential execution.

### LOG IT
Record observations, state transitions, determinations, authority changes, evidence and consequence decisions contemporaneously.

### PROVE IT
Bound every claim to preserved evidence capable of independent inspection and reconstruction.
